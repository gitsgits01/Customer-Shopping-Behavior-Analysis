# Customer-Shopping-Behavior-Analysis
Performed Customer Shopping Behavior analysis using, Python, SQL Server and Power BI.

This project demonstrates a complete data analytics workflow—from data loading to visualization. The goal is to extract meaningful insights from raw data using Python, SQL, and interactive dashboards.

The project covers:
Data loading and preprocessing
Exploratory Data Analysis (EDA)
Data cleaning
SQL analysis using SQL Server
Dashboard creation in Power BI

The dataset used in this project contains customer shopping behavior, including:
Customer details
Product categories
Purchase history
Ratings and reviews

Tools & Technologies
Python (Data processing & EDA)
Pandas
SQL Server (Data querying & analysis)
Power BI Desktop (Data visualization & dashboarding)

Project Steps
1. Data Loading (Python)
Imported dataset using Pandas
Checked structure, data types, and missing values

2. Exploratory Data Analysis (EDA)
Analyzed distributions, trends, and relationships
Visualized data using charts and graphs
Identified patterns and anomalies

3. Data Cleaning
Handled missing values
Removed duplicates
Corrected inconsistent data types
Prepared dataset for analysis

4. SQL Analysis (SQL Server)
Loaded cleaned data into SQL Server
Wrote queries to:
Calculate averages and totals
Identify top-performing categories/products
Analyze customer behavior

6. Dashboard (Power BI)
Connected SQL Server to Power BI
Built interactive dashboard including:
Sales trends
Category performance
Customer insights
Used filters and visuals for better understanding

Results & Insights
Identified high-performing product categories
Discovered customer purchasing patterns
Highlighted areas for business improvement
Provided data-driven insights for decision-making

This project showcases end-to-end data analysis skills, combining Python, SQL, and Power BI to transform raw data into actionable insights.
